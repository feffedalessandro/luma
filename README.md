# LUMA

LUMA is a clam shaped interactive lamp designed to guide users
through a ten minute mindfulness ritual.

## My role

I worked on the wiring, Arduino code and physical assembly.
I also collaborated with the 3D designer to integrate the
hardware into the shell and with the UI designer to synchronise
the lamp with the ProtoPie interface.

## Hardware
Input
- TTP223 Touch sensor
- Push Button
- HC-SR04 Ultrasonic sensor
- Photoresistor

Output
- SG90 Micro Servo motor
- 8-LED NeoPixel ring
- DFPlayer Mini MP3

Controller
- Elegoo UNO R3

## Software

- Arduino
- ProtoPie
